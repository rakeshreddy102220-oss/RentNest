# RentNest

RentNest is a premium, full-stack rental marketplace with separate Owner, Tenant, and Admin portals.

## Features
- Landing page with modern portal cards and glassmorphism UI.
- Secure authentication with role-based access.
- Owner dashboard, add property page, tenant search, property details, admin dashboard.
- Backend powered by Express and SQLite.
- Frontend built with React, Vite, and Tailwind CSS.

## Run locally

1. Install dependencies:
   - `npm install`
   - `npm run install:all`
2. Start the app:
   - `npm run dev`
3. Open the frontend at `http://localhost:4173`

## Sample credentials

- Owner: `owner@rentnest.com` / `owner123`
- Tenant: `tenant@rentnest.com` / `tenant123`
- Admin: `admin@rentnest.com` / `admin123`
